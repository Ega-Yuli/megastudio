# ContentHub (Static)
Website statis ringan untuk mem-publish artikel & pemasaran produk tanpa backend.

## Struktur
- `index.html` — daftar konten dari `data/posts.json`
- `profile.html` — halaman profil pemilik
- `assets/style.css` — gaya tema krem–kuning
- `assets/app.js` — JS untuk render konten
- `data/posts.json` — "database" sederhana JSON
- `assets/img/` — gambar

## Edit Konten
Ubah `data/posts.json` lalu commit & push. GitHub Pages akan otomatis memuat perubahan.
